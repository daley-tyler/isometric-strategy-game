# Controls

The toolbar and contextual panel provide the normal construction and unit actions. Most keyboard construction shortcuts apply immediately to the selected tile, while toolbar buttons show a placement preview first.

| Action | Keys |
| --- | --- |
| Pan | WASD, arrows, or middle-mouse drag |
| Zoom | Wheel, `+` / `=`, `-` |
| Select | Left-click |
| Cancel placement or selection | Escape; right-click cancels an active mode |
| Road, housing zone, commercial zone | R, 1, 2 |
| Power, water, fire station | 3, 4, 5 |
| Bulldoze | B |
| Farm, materials plant, refinery, import depot | F, M, Y, I |
| Defense factory | G when no unit is selected |
| University, laboratory, next research | U, L, T |
| Barracks, vehicle factory, drone factory, airbase | N, V, O, H |
| SAM site, missile silo | 7, 8 |
| Cycle import resource, order import | Comma, period |
| Queue infantry, tank, artillery, robot | Q, E, C, X |
| Queue recon drone, bomber, fighter | Z, J, K |
| Deploy infantry, tank, artillery, robot, recon, bomber, fighter | F1 through F7 |
| Move or attack selected unit | Right-click empty ground or an enemy |
| Defend, stop | G with a unit selected, Space |
| Manufacture missile, target missile | F9, F10 with a silo selected |
| Diagnostics | F3 |

F8 spawns a developer AI test force and bypasses normal production. It is not part of ordinary campaign progression. P and Delete/Backspace add and remove development map markers.

All buildings occupy one logical tile even when their sprites overhang it. Materials plants require iron or stone on the tile or an adjacent tile; refineries similarly require oil. Capital capture is performed by ground units and takes two simulation ticks in the current configuration.

Save and load are buttons in the right-hand Game section. Manual saving is disabled while a victory or defeat summary is open. Victory offers Continue in Sandbox; defeat offers Load Latest Autosave or Restart Prototype.
